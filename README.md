# KH1 Save Anywhere

Save and change your party anywhere. Pressing Start opens the save point
menu instead of the normal menu, and its "Menu" option still takes you to the
normal menu. Loading a save puts you right where you saved. Cutscenes, fights
and the gummi ship keep their normal pause.

## Requirements

- Kingdom Hearts Final Mix, Steam version
- LuaBackend, installed through OpenKH Mods Manager
